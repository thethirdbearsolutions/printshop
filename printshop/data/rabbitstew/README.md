# Bundled rabbitstew runs

Copies of a few committed rabbitstew files, so champions build without a rabbitstew checkout.
Each directory is a run's `config.json` plus the genomes used here, unchanged.

| Directory | Source (rabbitstew `5830288`) |
|---|---|
| `RBT-19-P-801/` | `runs/RBT-19/P-801/config.json`, `runs/RBT-19/P-801/holistic/best_gen0590.json` |

Any other run works too: pass its directory in a rabbitstew checkout (`runs/RBT-19/P-801`).
